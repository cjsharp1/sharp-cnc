Real COM → Linked

Power → USB → Refresh → COM → Connect (115200) → Linked

Hook the PC to Chris’s Demon Shield with USB so they can talk. “Linked” means the chat line is open. Connect does not home or jog.

  1. Power the Demon Shield / Arduino safely. Plug USB from the PC. Prefer steppers at low risk until positions look sane (first-test Stage 1).

    Expect Windows may chirp for a new COM device; board stays powered.

  2. Disconnect Virtual if needed → Refresh → pick the Demon Shield COM → Connect at 115200.

    Expect Strip shows Linked; live Material / Machine XYZ. Soft reset (`Ctrl-X`) on connect.

  3. First real session: sit linked for a minute. Glance at status / activity. Do not jog, home, or Start yet (Stage 1 Pass). Disconnect / reconnect once.

    Expect Link stays up; no unexpected motion. Failures → stop; fix port / cable / drivers before Unlock or motion.

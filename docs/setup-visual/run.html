Run

Supervise the cut — progress, feed / spindle overrides on the safety strip, Hold / Resume / Stop. No probe, load, Calibrate, or Advanced here. Stay at the machine. First-test Stage 4 scrap still Starts from Verify; Run is where you watch it.

Progress

Watch line / % · Material / Machine XYZ on the strip · optional current line

Run is the “eyes on the cut” room. The strip always shows Material XYZ (origin on the blank) and Machine XYZ (bed frame) — never “Work” in the UI.

  1. After Start in Verify, confirm the phase switcher shows Run and State is Run (or Hold).

    Expect Progress (line / %, time if known). Visualizer tracks the toolhead. Strip never hides.

  2. Keep one hand near Abort / E-Stop. Know how to kill spindle power for a real cut (Stage 4).

    Expect UI E-Stop / enclosure Abort are soft reset / hold — not wall power.

2

Overrides + Hold / Stop

Feed % · spindle % · Hold / Resume / Stop (mirror Demon Shield)

Slow the cut with feed override; pause with Hold; abort with Stop. Same ideas as the enclosure buttons when wired.

  1. Adjust Feed % / Spindle % on the strip if needed (e.g. 70–90% feed on first scrap).

    Expect Overrides take effect while streaming or in Hold; strip stays visible.

  2. Practice once: Hold → Resume (UI and enclosure if wired). Then Stop / Abort if you need to cancel.

    Expect Hold freezes motion; Resume continues; Stop soft-resets / cancels the stream. Alarm → Unlock only when clear.

Not in Run (except during an M6 pause): Probe, Calibrate, job load, console / macros / G54–G59 (those are Menu → Advanced… only).

3

Tool change (M6)

Idle → spindle stop → change bit → re-probe Z → Continue

The app waits until the machine stops moving, turns the spindle off, then asks you to change the bit and re-zero Z before it spins back up.

  1. When a job hits M6, wait for the strip: Spindle stopped ✓.

    Expect Machine Idle, then M5. Do not touch the bit before this.

  2. Change the bit. Re-probe Z (or tick Same tool length if it did not change). Then Continue.

    Expect Continue stays disabled until re-probe or same-length. Spindle restores with a short dwell, then the job resumes.

4

After the job

Complete / Stop → Verify · new blank → Prepare · Disconnect → Connect

Same job again? Back to Verify. New piece of wood? Prepare. Unplug the session? Connect (Phase 0).

  1. Job complete or Stop: review in Verify (same path) or clear and return to Prepare.

    Expect Streaming ends; Start gated again until ready + soft-limit OK.

  2. After Stage 4 scrap Pass: still Simulate every new path; keep soft travel honest; never leave a Running job unattended.

    Expect Careful real parts only after first-test stages Pass on iron — see First-test stages.

Getting started

Four steps from empty PC to a linked controller. Full detail lives in the user guide chapters linked below.

  1. Get SharpCNC on Windows

    Prefer the Windows installer from GitHub Releases. To develop from source, clone github.com/cjsharp1/sharp-cnc and install Node.js 20+ plus Rust.

  2. Open the desktop app

    After installing, launch SharpCNC from the Start menu. From source, run npm install, then npm run tauri dev for real USB serial. For UI practice without hardware, use npm run dev (mock GRBL only).

  3. Connect to the machine

    Power the CNC safely, plug USB into the Demon Shield / Arduino, refresh ports, pick the COM port, and Connect at 115200 baud. Wait for Linked and live Work / Machine coordinates.

  4. First things to do

    Run Menu → Calibration… once so soft travel matches the bed. Set material & tool, load a .nc / .gcode (or SVG), use Prepare to run… (XY + Z probe), Simulate, then Start when ready. Keep E-Stop within reach.

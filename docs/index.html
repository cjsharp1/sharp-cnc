SharpCNC

Personal GRBL controller for one specific CNC — Connect → Calibrate → Prepare → Verify → Run, with a live machine view.

Built for Chris’s Demon Shield + GRBL machine only — not a multi-machine CAM or UGS replacement. Windows desktop first (Tauri + USB serial). Same workshop steel and brass look as the app.

Getting started

Four steps from empty PC to a linked controller for this Demon Shield + GRBL rig (other machines are out of scope). Full detail lives in the user guide chapters linked below.

  1. Get SharpCNC on Windows

    Prefer the Windows installer from GitHub Releases. To develop from source, clone github.com/cjsharp1/sharp-cnc and install Node.js 20+ plus Rust.

  2. Open the desktop app

    After installing, launch SharpCNC from the Start menu. From source, run npm install, then npm run tauri dev for real USB serial. For UI practice without hardware, use npm run dev (mock GRBL only).

  3. Connect (Phase 0)

    Prefer Virtual CNC for a first practice pass. For real iron: power the CNC safely, plug USB into the Demon Shield / Arduino, refresh ports, pick the COM port, and Connect at 115200 baud. Wait for Linked and live Material / Machine coordinates.

  4. Calibrate once, then Prepare → Verify → Run

    1 · Calibrate (once per machine, or after hardware change): $3 · steps/mm · soft travel — fresh install can bootstrap via First-run. Next sessions skip to Prepare. 2 · Every job: Prepare (stock · Material XYZ · Z · load · Mark ready) → Verify (Simulate → Start) → Run. Connect guide: Phase 0. Keep E-Stop within reach.

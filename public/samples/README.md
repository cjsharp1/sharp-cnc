# SharpCNC cut-size samples

Built-in SVGs with **real millimetre units** (`width`/`height` in `mm`, matching `viewBox`) so **100 mm in the file = 100 mm in SharpCNC**.

| File | Geometry | Use |
|------|----------|-----|
| [`sample-100mm-square.svg`](sample-100mm-square.svg) | 100 × 100 mm closed square | Primary cut-size / steps/mm check |
| [`sample-50mm-square.svg`](sample-50mm-square.svg) | 50 × 50 mm closed square | Smaller stock / quick check |
| [`sample-100mm-line.svg`](sample-100mm-line.svg) | 100 mm line + end ticks | Single-axis length check |

Also available from the Job → SVG panel (**Samples**) and from the [user guide](../../docs/user-guide/08-jobs-and-svg.md#cut-size-samples). Guide file copies: `docs/user-guide/assets/samples/`.
